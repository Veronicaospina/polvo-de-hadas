# Polvo de Hadas 🎀

Explorador de personajes de Disney hecho con React, TypeScript, React Router, Zustand y Tailwind CSS. Es el Proyecto 01 de Desarrollo Front-End.

Los datos vienen de [Disney API](https://disneyapi.dev). Es un proyecto universitario sin relación oficial con Disney.

## Correr el proyecto

```bash
pnpm install
pnpm dev
```

## Rutas

| Ruta | Vista |
| --- | --- |
| `/` | Inicio |
| `/explorar` | Lista de personajes con búsqueda y filtro |
| `/explorar/:id` | Detalle de un personaje |
| `/favoritos` | Personajes guardados |
| `/contacto` | Formulario de contacto |
| `*` | Página 404 |
